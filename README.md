## 📌 About the Project

**UrbanCart** is a fully functional e-commerce platform inspired by Amazon and Flipkart. Built using the **MERN stack** and styled with **Tailwind CSS**, the application offers a smooth user experience with powerful features tailored for online shopping.

---

## 🚀 Features

### 🛍️ User Features

- 🔐 **User Authentication**
  - Sign up with email and upload profile picture.
  - Login/logout functionality.
- 🛒 **Shopping Features**
  - Add products to cart.
  - View and manage cart items.
  - Checkout (payment feature coming soon).
- 🔍 **Search and Filters**
  - Search bar for products.
  - Filter by category.
  - Sort by price: Low to High / High to Low.
- 🧾 **Product Listing**
  - Renders a large number of products dynamically.
  - Responsive design for desktop and mobile.
